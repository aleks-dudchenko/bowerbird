# Zbirka

Локальна бібліотека дизайн-референсів для macOS. Офлайн, без акаунта,
без підписки. Файли лежать у звичайній папці — застосунок їх не привласнює.

> **Статус: M1 — бібліотека працює.** Імпорт перетягуванням, сайдкари,
> тумбнейли, сітка, редагування тегів і нотаток. Пошуку ще немає — це M2.
> Дорожня карта — у [PLAN.md](PLAN.md).

## Принципи

- **Папка — джерело правди.** Поряд із кожним файлом лежить сайдкар `.json`
  з тегами й нотатками. SQLite — лише кеш, який завжди можна перебудувати.
  Видалиш застосунок — бібліотека залишиться читабельною.
- **Нічого не йде в мережу.** AI-пошук працює локально, без API-ключів.
- **Без акаунтів, пейволів і телеметрії.**

## Запуск

```
npm install
npm run dev     # запуск
npm run smoke   # перевірка дискового шару, 12 тестів
```
